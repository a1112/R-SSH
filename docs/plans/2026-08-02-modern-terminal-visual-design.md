# R-SSH 现代深色终端视觉设计

## 目标

将 R-SSH 的默认视觉从当前高密度、低层次的灰黑界面调整为现代深色终端风格，同时保持现有 WezTerm 配置兼容、Unicode shaping、字体 fallback 和 GPU 渲染行为。

成功标准：

- 英文等宽字符清晰、列对齐稳定，中文和其他脚本继续由系统字体 fallback。
- 终端正文、标签栏、光标、选区和 ANSI 颜色形成明确层级。
- 长输出、OpenCode、Claude Code、Codex、Git 彩色日志和 Unicode 混排均无重影、裁切或 tofu。
- 用户配置的字体、颜色、字号和 padding 仍能覆盖默认值。

## 视觉方向

采用现代深海蓝方案：

- 主字体：Windows 使用 Cascadia Mono，macOS 使用 Menlo，Linux 使用 Noto Sans Mono；不可用时依次使用 Source Code Pro、Consolas 和现有 Noto Sans fixture。命令面板、选择器和窗口 frame 默认沿用同一平台等宽家族，显式 WezTerm 字体配置仍优先。
- 字体 fallback：保留 Noto Sans SC/JP、Microsoft YaHei、Meiryo、Malgun Gothic、Segoe UI、Nirmala UI 和 emoji 字体。
- 终端背景：`#0B1220`。
- 默认前景：`#D8E2F0`。
- 命令面板和字符选择使用 `#101827` 浮层与 `#D8E2F0` 前景；pane 选择保持终端内容可见，但使用 `#0B1220` 的 90% 不透明浮层和同一前景层级。
- 命令面板、输入/字符选择器和 Tab Navigator 的当前行统一使用 `#38BDF8` cyan 强调面与 `#0B1220` 深色文字；快捷键标签沿用同一强调面，避免旧的黄黑色块打断层级。
- 弱化前景：`#8492A6`。
- 光标：`#67E8F9`，光标文字使用深色背景色。
- 选区：蓝灰色半透明效果，对比清晰但不刺眼。
- Quick Select 标签使用 `#38BDF8` cyan 强调面与 `#0B1220` 深色文字；显式 `quick_select_label_fg/bg` 配置仍优先。
- pane badge 使用 `#1B2B44` 活动表面与 `#D8E2F0` 前景，debug overlay 使用 `#101827` 表面，保持与标签栏和选择浮层一致。
- pane split 分隔线使用 `#38BDF8` 活动线、`#475569` 非活动线和 `#101827` 底面；显式 `colors.split` 仍只覆盖前景色。
- pane inspection 使用 `#1B2B44` 活动表面与 `#D8E2F0` 前景，避免调试信息覆盖层回到高亮青白旧色。
- 长输出滚动条使用 `#101827` 轨道与 `#475569` 滑块；显式 `colors.scrollbar_thumb` 仍覆盖滑块颜色，滚动范围和命中行为不变。
- 分屏 pane 关闭按钮使用 `×` 字形、`#F87171` 危险操作表面与 `#0B1220` 深色前景；仅调整默认绘制层级，不改变确认和命中行为。
- 默认标签页关闭格静止时保持高亮 `×`，悬停时切换为同一 `#F87171` 危险操作表面与 `#0B1220` 深色前景；显式 `tab_bar_style` 或标签颜色仍优先，命中列不变。
- 标签栏背景：`#080D18`；活动标签：`#1B2B44`；非活动标签：`#101827`。
- 状态和焦点强调色：`#38BDF8`。

ANSI 调色板避免纯黑和高饱和荧光色，保持日志、编译器诊断和 AI CLI 语义颜色易辨识。红色用于错误，黄色用于警告，绿色用于成功，蓝青色用于链接、提示和活动状态。

## 字体与网格

GPU 文本后端优先加载平台等宽字体，不将窗口 DPI 再次叠加到物理像素网格。默认字体大小和网格必须成对调整，保证字形不会跨越行边界。

窗口创建和跨显示器迁移使用物理窗口尺寸，终端单元格与 GPU 字形 atlas 同步采用有效 DPI；因此 4K/125–200% 缩放不会把同一组行列放大成双倍 PTY 宽度，也不会让字形落入相邻行。

概念保真默认目标为 17px Cascadia Mono、10px 单元格宽度和 21px 单元格高度，让 PowerShell/AI CLI 长输出在 16:10 窗口中保持舒展可读。若真实 GPU 截图显示基线或宽字符对齐异常，则保持字体与网格成对回退；显式字号、cell_width 和 line_height 仍优先。

中文宽字符必须占两个逻辑单元格；字体 fallback 只能改变字形来源，不能改变终端模型的列宽。

## 布局

默认窗口内容增加 14px 左右 padding 和 10px 上下 padding。padding 参与内容区域计算，但不改变 PTY 报告的单元格尺寸。
现代默认窗口在这层物理留白最外侧绘制 1px `#475569` 细边框，作为非交互的
chrome 轮廓；四角留出一个像素形成轻微圆角，边框不覆盖终端内容，也不改变内容矩形、PTY 尺寸或鼠标命中映射。
标签栏底部增加 1px `#2B3B53` 分隔线，位于标签行自身的最后一个像素，不侵入首个终端行。

标签栏保持单行，使用更深的背景与清晰的活动标签。标题过长时继续按现有宽度规则裁切，不能通过压缩字形塞入标签。
现代默认活动标签保留约 22 个终端列的宽松 pill 表面，标题使用正常字重，把焦点强调交给蓝灰表面；关闭按钮靠近尾部并保留 2 个终端列的右侧呼吸空间，使紧凑 80 列窗口中的标题与焦点层级更接近目标；关闭按钮的命中列仍绑定到 `×` 本身。
活动表面首尾留白单元使用标签栏底色作角落裁切，形成轻量 pill 轮廓；裁切只影响绘制，不缩小标签的交互范围。

Windows 和其他现代默认窗口在真实渲染路径中增加非交互的深色 ASCII 徽章 `[>_]` 与 `R-SSH` 品牌段；徽章方括号使用加重的 `#38BDF8` cyan 轮廓，内部提示符使用可读的终端前景 `#D8E2F0`，产品名使用高强调前景 `#F8FAFC` 但保持正常字重，徽章使用活动表面的蓝灰底色；默认
workspace 名称不占用紧凑标题栏空间，自定义 workspace 名称仍使用弱化前景显示。默认 tab
徽章左侧保留两个终端列的内缩，标签与品牌之间再保留三个终端列的呼吸间距，隐藏 pane/index 诊断元数据并保留 `×` 关闭标记与高强调白色 `+` / 浅灰色 `#A5B4C7` `▾` 新建入口；`+` 与 `▾` 之间至少保留一个额外终端列的呼吸空间。显式 `tab_bar_style`
或标签配置仍优先，继续使用原始 WezTerm 标签格式。
现代紧凑标题栏的默认窗口控制符使用高亮前景 `#F8FAFC`，每个 glyph 两侧保留两个终端列的呼吸空间，以保持最小化、最大化和关闭入口在深色标题栏上的可见度；显式窗口按钮格式、前景或 `integrated_title_button_color` 仍覆盖该默认值。
默认窗口控制悬停时使用 `#1E293B` slate 表面，静止状态和显式 `button_bg/button_hover_bg` 配置保持原有优先级。

滚动条默认行为不变。光标、下划线、分隔线和选区颜色使用新调色板，但不改变交互语义。

## 配置优先级与降级

新字体和颜色只作为默认值。Lua 配置、内置配色方案、外部配色文件和命令行覆盖保持现有优先级。

若平台字体文件不存在，加载器跳过该候选并继续后续字体；最终始终保留内置 fixture，避免启动失败。单个系统字体损坏不得阻止窗口创建。

Windows 优先 Cascadia Mono；macOS 优先 Menlo/Monaco；Linux 优先 Noto Sans Mono/DejaVu Sans Mono。跨平台可以存在细微字形差异，但颜色、间距和终端列对齐必须一致。

## 效果图与实现验证

先生成一张 16:10 控制台效果图，包含标签栏、PowerShell 提示符、Git 状态、中文、ANSI 色块以及一段 AI CLI 输出，用于确认整体比例和颜色关系。

实现后以真实 R-SSH GPU 窗口截图替代概念稿进行最终判断，覆盖：

- 中文、日文、韩文、阿拉伯文、印地文和 emoji。
- OpenCode、Claude Code、Codex 的版本和帮助输出。
- Git 彩色日志、编译器诊断、ANSI 16 色和 35 行滚动输出。
- 100%、125% 和 150% Windows 缩放下的行距与基线。

自动验证包括字体选择/fallback、默认调色板、padding、损坏区域与完整重绘一致性、GPU 文本、原生窗口 E2E 和全 workspace 测试。

Windows native E2E 在 debug harness 中可通过
RSSH_TEST_WINDOW_SCALE_FACTOR=1.0|1.25|1.5 重放常见缩放档位；该注入只用于验证
窗口 DPI、字体栅格和 GPU present，不改变 release 用户行为。
